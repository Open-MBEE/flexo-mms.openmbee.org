# Community

Flexo is developed in the open by [Open-MBEE](https://www.openmbee.org/), a
[NumFOCUS](https://numfocus.org) sponsored project, under the Apache-2.0 license.

## Talk to us

- **Slack** — [openmbee.slack.com](https://openmbee.slack.com); the invitation link is on
  [openmbee.org](https://www.openmbee.org/).
- **Google Group** — [openmbee](https://groups.google.com/g/openmbee) for announcements
  and longer discussion.
- **Confluence** — the [Open-MBEE wiki](https://openmbee.atlassian.net/wiki/) holds
  design notes, meeting records and the Flexo pages that predate this site.

## Contribute

Every service is its own repository under the
[Open-MBEE GitHub organisation](https://github.com/Open-MBEE); the
[services](services/README.md) and [tools](tools/README.md) pages link each one. Issues
and pull requests go to the repository concerned. Most repositories follow git-flow: work
is branched from and merged to `develop`, and `main` or `master` holds releases.

This site is the [flexo.openmbee.org](https://github.com/Open-MBEE/flexo.openmbee.org)
repository — plain Markdown under `docs/`, rendered by MkDocs. Every page carries an edit
link; a pull request that fixes a description or adds a project is welcome.

## Conduct and governance

Open-MBEE's [code of conduct](https://www.openmbee.org/code-of-conduct.html) and
[governance](https://www.openmbee.org/governance.html) apply across all of its projects,
Flexo included.
